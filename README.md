# Mejórate

Web de asesoría de imagen masculina de **jjn.dzz** (Jano Arribas Díaz).

- Abre `index.html` en el navegador para verla.
- Teléfono (llamadas y WhatsApp), horario del calendario y guardado de reservas: bloque `CONFIG` al principio de `js/main.js`. Las fotos de la portada y la galería se eligen justo debajo (`PORTADA` y `GALERIA`).
- Cómo guardar las reservas: `RESERVAS.md`.
- Fotos: en `img/fotos/` (grande) y `img/fotos/thumb/` (pequeña).

El briefing completo del proyecto está en `CLAUDE.md`.
