# Mejórate

Web de asesoría de imagen masculina de **jjn.dzz** (Jano Arribas Díaz).

- Abre `index.html` en el navegador para verla.
- WhatsApp, horario del calendario, guardado de reservas y estilos del texto animado: bloque `CONFIG` al principio de `js/main.js`.
- Cómo guardar las reservas: `RESERVAS.md`.
- Fotos: guárdalas en `img/` y colócalas en los huecos marcados con la clase `empty` en `index.html`.

El briefing completo del proyecto está en `CLAUDE.md`.
